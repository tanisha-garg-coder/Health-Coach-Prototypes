Health Coach usability prototypes

Seven single-task prototypes wired for Maze usability testing. Point each Maze mission at the matching link below — every task launches with ?maze=1, which drops the participant straight into the chat for that task, hides the scenario switcher, and pre-fills the task prompt.

Setting up a Maze mission? Use the link on each card as the mission URL. Each prototype already carries the Maze universal tracking snippet — add your project API key once (see MAZE.md) and clicks, paths, and heatmaps are captured automatically. A participant reaches the goal when the “Task completed — continue in Maze” banner appears.
Prototypes render client-side (React is loaded from a CDN at runtime), so they must be opened over http(s) — e.g. GitHub Pages — not from the local filesystem. Full instructions in MAZE.md.
