Maze test launcher

Each card is a self-contained entry point for one Maze mission. Open a link to preview it, or copy the URL straight into a Maze block's prototype / live-website field.

Each task lands the participant directly in the chat with the question pre-filled — they just press send. When the AI's answer appears, the prototype adds #task-complete to the URL and shows a "Task completed — continue in Maze" marker, so the mission can auto-succeed. See MAZE.md for full setup.
