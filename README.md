# Health-Coach-Prototypes

Interactive **myScout** AI health-coach chat prototypes (Claude Design
components), used for usability testing.

- **Prototypes:** `Task N - ….dc.html` (Tasks 1–4 = diabetes, 5–7 = stress /
  mental health). Each is a self-contained page rendered by `support.js`.
- **Design system:** `_ds/` (League brand tokens, Inter Tight fonts, components).
- **Maze testing:** see [**MAZE.md**](MAZE.md) for how to publish these to
  GitHub Pages and wire them into Maze. Once published, the click-to-copy
  launcher lives at `maze/`.
